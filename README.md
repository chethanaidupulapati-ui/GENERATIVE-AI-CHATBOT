🌸 Generative AI Chatbot

A cozy and aesthetic AI chatbot built using Python and Streamlit.
It uses the Google Gemini API to generate intelligent responses.
The interface features a soft pink, purple, and floral theme with animations.
Users can enter questions or ideas through a simple text input.
The Gemini API processes the prompt and displays the generated response.
Run the project using streamlit run app.py.
